# CIMSL real photography — images/cimsl/

All photos downloaded from the live site https://cimsl.org (media library,
August–September 2026 uploads). They show CIMSL's actual field work in
Sierra Leone: community meals, school-supply distributions, family visits,
community gatherings and public events.

## Layout

- `logo/` — organisation identity
  - `cimsl-logo-trimmed.png` — full oval logo, margins trimmed (navbar + footer)
  - `cimsl-favicon.png` — emblem crop for the browser tab icon
- `hero/` — large landscape banners
  - `hero-community-meal.jpg` — home + donate heroes, OG image
  - `hero-children.jpg` — impact/contact/stories imagery
  - `hero-gathering.jpg` — programs/get-involved/news/events heroes
  - `hero-supplies.jpg` — sponsorship + supply-story imagery
- `programs/` — one cover photo per program
  - `protection.jpg`, `education.jpg`, `healthcare.jpg`, `community.jpg`
- `about/` — organisation + event photos
  - `about-women.jpg`, `about-hall.jpg`, `about-podium.jpg`, `about-appeal.jpg`
- `gallery/` — 12 captioned gallery photos (`gallery-01…12`)

## Notes

- Source files were WhatsApp-camera JPEGs with device names; renamed here
  for clarity. Originals kept only upstream on cimsl.org.
- `default.png` (a grey theme placeholder) and the theme's stock banner were
  intentionally NOT imported — only authentic CIMSL imagery is used.
- The one `.mp4` in the media library was skipped (photo-only site).
- No identifying details of children are published beyond what cimsl.org
  itself shows; per policy, new stories need consent + anonymisation.
